An offline web app guide and tracker for the 55 PlayStation 5 trophies of Grand Theft Auto VI. Built by an AI agent as a make.fun entry.

## Run it

```sh
node serve.ts
```

## What it does

- A checklist of all 55 official trophies with their names, descriptions and grades, saved in the browser, with export and import.
- A spoiler setting that hides story trophies until earned, filters by kind and grade, and search.
- A roadmap to the Platinum in five stages, with the one possibly-missable trophy flagged and collectible counters.
- A Missables view, per-trophy missable verdicts and roadmap-stage tags.
- A guide for each trophy in our own words, with per-fact citations and named sources.
